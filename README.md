# SpunFix – 부직포 공정·품질 트러블슈팅 도우미

**"AI 코딩 도구의 도움을 받아 완성한 나만의 AI 웹 서비스"**

스펀본드(Spunbond) 부직포 제조 현장의 불량 증상과 제품 사양을 입력하면, AI가 **예상 원인 순위**, **현장 점검 포인트**, **단계별 조치 방향**을 즉시 분석하여 제공하는 실무 지원 웹 서비스입니다. 이 프로젝트는 순수 바닐라 웹 기술과 Vercel Serverless 기반으로 구성되었습니다.

## ✨ 주요 기능 및 UX 고도화 (보너스 구현)

본 서비스는 사용자의 경험(UX)을 개선하고, 안정적인 운영을 위해 다양한 기능이 고도화되어 있습니다.

1. **AI 기반 트러블슈팅 진단**: 불량 대분류/발생구간 및 상세 증상 입력 시 맞춤형 조치 가이드 제공. (Claude 3 Haiku 모델 활용)
2. **유연한 입력(모름 옵션) 및 동적 토큰 제어**: 발생 구간 등을 정확히 모를 경우 "모름"을 선택할 수 있으며, 이 경우 AI 응답 길이를 동적으로 조절하여 타임아웃을 방지합니다.
3. **마이크로 인터랙션 (사용성 개선)**:
   - 필수값 누락 시 **자동 스크롤 및 붉은색 테두리 하이라이트** 적용.
   - 분석 요청 시 직관적인 **로딩 스피너 및 경과 시간(초 단위) 타이머** 제공.
4. **결과 다운로드 (.md)**: AI가 분석한 진단 리포트를 개인 기기에 마크다운 파일로 쉽게 보관할 수 있습니다.
5. **안정성 강화 (에러 핸들링)**: 90초 프론트엔드 타임아웃 처리 및 각 오류 상황(4xx, 5xx, 빈 입력 등)별 명확한 한국어 안내 메시지 제공.

## ⚙️ 실행 및 배포 가이드

본 프로젝트는 Vercel을 통해 프론트엔드 파일(HTML/CSS/JS)과 백엔드 Python 서버리스 함수를 통합 서비스합니다. 모든 개발 작업과 실행은 **`spunfix/` 폴더 내부**를 기준으로 진행합니다.

### 1) 로컬(내 컴퓨터) 실행 방법
1. 터미널(또는 명령 프롬프트)을 열고 실제 코드가 있는 **`spunfix` 폴더 안으로 이동**합니다. (`cd spunfix`)
2. Vercel CLI(가상 서버 도구)가 설치되어 있어야 합니다. (`npm install -g vercel`)
3. 해당 폴더에서 `.env.example` 파일을 복사하여 `.env` 파일을 생성합니다.
4. `.env` 파일 안에 본인의 API 키를 등록합니다. (아래 환경 변수 설정 방법 참고)
5. `vercel dev` 명령어를 입력하고 엔터를 칩니다.
6. 화면에 안내되는 주소(예: `http://localhost:3000`)를 브라우저에 입력하면 내 컴퓨터에서 서비스 테스트가 가능합니다.

### 2) Vercel 서버 배포 방법
1. 작업한 전체 코드를 GitHub 저장소에 `Commit` 및 `Push` 합니다. (GitHub Desktop 활용 권장)
2. [Vercel 홈페이지](https://vercel.com/)에 로그인하고, **"Add New..." → "Project"**를 선택하여 해당 GitHub 저장소를 Import 합니다.
3. Import 설정 화면 아래쪽의 **Environment Variables(환경 변수)** 탭을 펼쳐, 아래 안내된 환경 변수 키워드와 값을 안전하게 등록합니다.
4. **"Deploy(배포)"** 버튼을 클릭합니다. 잠시 후 성공적으로 빌드가 완료되면 나만의 배포 URL이 제공됩니다.

## 🔑 환경 변수 (API 키) 설정 방법

GitHub에 코드가 올라갈 때 비밀번호(API 키)가 유출되는 것을 막기 위해, 코드가 아닌 '환경 변수'라는 금고에 키를 보관해야 합니다.

### 필수 등록 환경 변수:
| 변수명 (Name) | 설명 | 예시 값 (Value) |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Claude AI 모델을 호출하기 위한 필수 인증 키 | `sk-ant-api03-...` |
| `ANTHROPIC_BASE_URL` | AI API 프록시 서버 주소 (주어진 경우 필수) | `https://copa.codyssey.kr` |

- **로컬 실행 시**: `spunfix` 폴더 내에 만든 **`.env`** 파일 안에 위 변수들을 등록합니다. (`.gitignore`에 의해 이 파일은 GitHub에 올라가지 않습니다.)
- **Vercel 배포 시**: Vercel 대시보드 → 프로젝트 선택 → **Settings → Environment Variables** 메뉴에 위 두 가지 키와 값을 추가합니다. (설정 후 재배포가 필요할 수 있습니다.)
