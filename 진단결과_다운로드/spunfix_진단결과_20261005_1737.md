**▶ 발생 구간 추정**

"동일 위치에서 GSM 편차가 지속 발생"한다는 점에서, 문제는 **방사(Spinning) ~ 적층(Web Formation) 구간**일 가능성이 가장 높습니다.
특정 위치가 반복된다는 것은 무작위 변동이 아닌 **구조적·고정적 원인**이 존재함을 의미합니다.

---

**1. 예상 원인 순위 (상위 3가지)**

**① 다이(Die) 또는 특정 방사 팩 노즐 막힘·편차 (가능성 최상)**
- 특정 노즐이 막히거나 토출량이 줄면, 그 위치의 섬유 퇴적량이 줄어 GSM이 낮아짐
- 동일 CD(Cross Direction) 위치에서 편차가 반복되는 경우 이 원인이 가장 유력
- PP 수지 탄화물·이물질이 노즐 내부에 누적될 때 주로 발생

**② 이젝터(Ejector) 또는 어테뉴에이터 에어 불균일**
- 섬유를 연신·이송하는 에어 압력이 CD 방향으로 균일하지 않으면 섬유 분포 편차 발생
- 에어 슬롯 일부 막힘, 에어 공급 밸브 불량 시 특정 위치에 섬유가 쏠리거나 부족해짐

**③ 컨베이어 벨트 흡입(Suction) 불균일**
- 벨트 하부 흡입 챔버의 특정 구간 막힘 또는 댐퍼 이상 시, 섬유 포집량이 위치별로 달라짐
- 흡입이 약한 위치는 섬유가 날려 GSM 저하, 강한 위치는 GSM 과다 발생 가능

---

**2. 현장 점검 포인트**

**GSM 편차 위치 파악 (최우선)**
- 생산 중 또는 정지 후 CD 방향으로 등간격 샘플 채취 (예: 10점 이상)
- 편차 위치가 CD 기준 일정한지, MD(기계방향) 기준 주기적인지 구분
- 편차가 CD 특정 위치 고정 → 노즐/에어 슬롯 점검
- 편차가 MD 방향으로 주기적 → 벨트 또는 롤 편심 점검

**노즐·방사 팩 점검**
- 다이 하부 노즐 육안 확인: 막힘, 탄화물, 폴리머 고착 여부
- 각 팩별 압력 게이지 수치 비교 → 편차 발생 팩 식별

**이젝터/에어 시스템 점검**
- 에어 슬롯 간격 및 막힘 여부 육안 확인
- CD 방향 에어 압력 분포 측정 (가능한 경우 포터블 압력계 활용)

**컨베이어 흡입 챔버 점검**
- 챔버 내부 이물질·보풀 누적 여부 확인
- 댐퍼 개도 위치가 설정값과 일치하는지 확인

---

**3. 단계별 조치 방향**

**[즉각 조치]**
- CD 방향 GSM 분포 데이터 확보 → 편차 위치 정확히 특정
- 해당 위치 대응 노즐 번호 또는 에어 슬롯 구간 식별
- 불량 롤은 별도 격리 후 판정 보류 처리

**[공정 조정]**
- 막힌 노즐 확인 시: 퍼지(Purge) 실시 또는 해당 팩 교체 일정 수립
- 에어 압력 편차 확인 시: 슬롯 청소 후 CD 방향 압력 재조정
- 흡입 불균일 확인 시: 챔버 청소 후 댐퍼 개도 재설정
- 조정 후 시험 생산 → GSM 재측정으로 개선 여부 검증

**[예방 조치]**
- 노즐·팩 정기 청소 및 점검 주기 표준화 (예: 주 1회 이상)
- CD 방향 GSM 프로파일 정기 모니터링 루틴 수립
- 에어 압력, 흡입 챔버 차압 관리 항목 일상 점검표에 포함
- 원료(PP) 수분·MFI 로트별 입고 검사 강화 (이물 혼입 방지)

---

**4. 안전 수칙**

- 다이 및 방사 팩 점검 시 **고온 화상 위험** → 내열 장갑·보호복 필수 착용
- 에어 슬롯·이젝터 점검 시 고압 에어 **잔압 확인 후** 작업 (에어 차단 Lock-out 적용)
- 컨베이어 벨트 내부 흡입 챔버 진입 시 **설비 정지 및 안전 잠금(LOTO)** 후 작업
- 퍼지 작업 시 용융 수지 비산 가능 → 보안경 착용 필수
- 2인 1조 작업 원칙 준수
